### ⚙️ KubASIE — Kubernetes Auto-Scaling Intelligence Engine

> **ML-powered predictive Kubernetes auto-scaler** that decides *before* the load hits — not after.

**GitHub:** [github.com/Ashish241/KubASIE](https://github.com/Ashish241/KubASIE)

<img align="right" src="https://github.com/Ashish241/KubASIE/blob/main/docs/images/KubASIE%20architecture%20with%20machine%20learning%20integration.png" alt="KubASIE Architecture — ML-Powered Kubernetes Auto-Scaler" width="40%"/>

| What | How |
|---|---|
| Time-series forecasting | LSTM + Prophet models |
| Scaling decisions | Custom policy engine overriding HPA |
| API layer | FastAPI microservice |
| Observability | Prometheus metrics |
| Deployment | Docker + Kubernetes + Helm |

**Key outcomes:**
- ✅ Reduced reactive scaling delays under bursty traffic
- ✅ Improved SLA stability with proactive pod management  
- ✅ Optimized cost by avoiding over-provisioning during low-traffic periods
